Privacy Policy — TFB Knowledge Hub

Last updated: 8 October 2026

What the app is

TFB Knowledge Hub is a private tool used only by the author of the YouTube channel The Financial Backstory. It is not offered to the public.

What data it accesses

The app uses a single Google permission, https://www.googleapis.com/auth/drive.file. With it, the app can only create, read and update the files it creates itself (a folder and the research documents inside it) in the channel's own Google Drive. It cannot see or change any other file.

What it does with the data

The documents contain the channel's own research notes about historical financial events (sources, quotations from public documents, fact-checking status). They are written by the channel's server and read by the channel's author.

The app does not collect personal data about other people, does not use the data for advertising, does not sell or share it with third parties, and does not transfer it anywhere other than the channel's own Google Drive.

Storage and security

The authorization token is stored only on the channel's private server, in a protected file readable only by the system. Access can be revoked at any time from the Google Account settings (Security → Third-party apps with account access).

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
