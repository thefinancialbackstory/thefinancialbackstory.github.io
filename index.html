The Financial Backstory — Knowledge Hub

The Financial Backstory is a documentary YouTube channel about the history of finance: markets, crises, companies and the people behind them.

The TFB Knowledge Hub is the channel's private research tool. It writes the channel's own research notes (verified sources, open questions, fact-checking status) as Google Docs in a single folder of the channel's Google Drive, so the author can read them while working on new episodes.

It is used only by the channel's author, on the channel's own Google account. It requests a single permission, drive.file, which lets it see and edit only the files it creates itself — nothing else in the Drive.
